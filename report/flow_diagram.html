Block Design 现状：28 个单元，悬空输入 0 个。
所有还没有数据源的输入都收敛到 vs_defaults 这一个块上——Vivado 对未连接的输入 只给一条 CRITICAL WARNING（BD 41-759）然后静默 tie 成 0， 那会让人分不清"本来就该是 0"和"忘了接线"。集中到一处之后，数据流图上一眼就能看出 哪部分是占位。该块里已经算出真值的只有两个：no_candidate = (n_bins_sel == 0) 与 n_free_bins = popcount(free_mask)。

仍然是占位的量（详见 report/design_report.md 第 6 节近似清单 A1–A10）：
1. 共模参考通道尚未接入：null_model_cancel 的 ref_i / ref_q 由 vs_defaults 送 0，即只做呼吸谐波抵消（等价于 Python 的 _harmonic_residual）。共模去除（_common_mode_reference 的 SVD 主成分） 已在 cm_ref_extract.v 中写好，但还没有被引擎调度。
2. support（分量一致度）取占位 0.8，contrast_db_q8 取 12 dB （= 不惩罚）。Python 里它们来自逐 (bin,RX) 的 argmax 一致性统计与 20·log10(对比度)， 需要分量级暂存 + MAD 单元才做得出来。
3. fr_inc_nominal 取标称 0.30 Hz 的相位增量，而不是由呼吸峰实测换算。
4. radar_loc_* 置 0，即 Ablation A 的雷达自定位回退关闭，只用视觉距离选仓。
5. reg_motion_thresh / reg_ctrl 目前由常量给默认值（100 mm/s、使能测量）， 正式版本应由 PS 通过第二路 AXI GPIO 写入。
