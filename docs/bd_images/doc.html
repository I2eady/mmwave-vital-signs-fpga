ZYNQ7020 毫米波雷达非接触心率估计 —— Block Design 算法模块与连接关系

器件 xc7z020clg400-2。Block Design 名称 vs_bd，共 28 个单元：19 个算法模块实例（17 个模块，fir_bandpass 与 goertzel_sweep 各例化两次）+ 6 个 Xilinx IP + 3 个 xlconstant。

本文中的模块图与连接表由脚本 scripts/gen_bd_doc_assets.py 直接从 rtl/**/*.v 的端口声明与 tcl/build_bd.tcl 的 vs_net / vs_link 连线解析生成，共 129 条连线，与工程完全一致，不是手绘。

一、算法模块总览

数据流自上而下经过 7 级；vs_engine_fsm 是控制中枢，它逐候选通道调度整个流程，因此两个 FIR 与两个 DFT 在时间上是分时复用的，并不会同时工作。

结论：算法结构本身没问题（综合全部通过），但存储器的映射方式让设计放不进 xc7z020 —— 1.15 Mbit 的窗口存储器被实现成分布式 RAM（48000 个 LUT），而 BRAM 一个都没用上。根因是 integrate_detrend.v 的 S_APPLY 状态里 ap_val = mem[ap_idx] 是组合读，BRAM 做不到异步读。改法见 docs/BlockDesign结构说明.md 第六节。
